# Cloudflare Workers AI 免费配额

提供方：Cloudflare。资源类型：API。

分类：[模型 API 与推理额度](../categories/api.md)

## 可获得的权益

每日免费10,000 Neurons；用量每日UTC 00:00重置，模型按各自Neuron换算率消耗。

## 申请资格

Workers Free或Paid账户；部分模型另要求付费付款方式。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

开启Workers AI并选模型，通过仪表板追踪每日Neuron用量。

## 额度、期限与使用限制

Neurons不是token或GPU小时，不同模型不能直接按同一token数换算。

## 费用与到期处理

超出免费量需Workers Paid；当前额外用量为每1000 Neurons 0.011美元，另核对模型专项价格。
