# Lambda GPU Cloud

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：可使用**　｜　**资料核对：2026-10-03**

提供方：Lambda。资源类型：GPU。

分类：[低价 GPU 与按量计算](../categories/low-cost.md)

## 可获得的权益

提供自助GPU实例与长期集群，价目区分每GPU小时、GPU数量、CPU和内存。

## 申请资格

可付费账户；自助实例按库存先到先得。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

在Instances价目选择1/2/4/8卡规格，核算整台实例总价后创建。

## 额度、期限与使用限制

每GPU小时价格必须乘GPU数量；多卡集群合同价不能当单卡随租价格。

## 费用与到期处理

税费另计；预留容量和自助实例合同条件不同。

## 补充说明

作为专项GPU云比价选项收录，不代表其每种GPU都比所有供应商便宜。
