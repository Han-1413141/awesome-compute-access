分类：[免费计算与云试用](../categories/free-compute.md) · [学生与教学计划](../categories/education.md)

## 可获得的权益

个人Free账户每月120核心小时与15GB-month存储；Pro为180核心小时与20GB-month。

## 申请资格

GitHub个人账户；组织与企业计划不自动享有同样免费配额。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

从仓库打开Codespace，按机器核心数估算可用时长，并在Billing检查预算。

## 额度、期限与使用限制

120核心小时在2核机器上约60个实际小时；不是120小时任意规格，也不包含GPU。

## 费用与到期处理

停止计算后保留的Codespace仍消耗存储；有付款方式时超配额会计费。
