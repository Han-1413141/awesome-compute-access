# 低价算力如何比较

[返回首页](../README.md) · [低价GPU目录](categories/low-cost.md)

先让候选实例满足任务要求，再比较完成同一任务的总成本。H100、RTX4090、A100和CPU服务器不能仅按“每小时多少钱”横向排名。

| 要比较的字段 | 原因 |
|---|---|
| GPU型号、显存、卡数 | 决定模型能否装入、批大小与并行策略 |
| PCIe/SXM、互联、精度能力 | 同名GPU的多卡训练性能可能不同 |
| CPU、内存、磁盘与网络 | 数据预处理和加载也会成为瓶颈 |
| 每GPU小时还是整机小时 | 8卡实例的单卡价不能当整机账单 |
| 按需、Spot、预留、Serverless | 抢占、承诺时间、冷启动和闲置计费不同 |
| 区域、税费与币种 | 影响最终账单与数据传输成本 |
| 磁盘、快照、IP、出网 | 关机后仍可能收费 |
| 预计有效运行时间 | 同价机器的任务完成时间未必相同 |

总成本可按“实例计费时长 × 实例价格 + 存储 + 网络 + 其他服务 + 抢占重跑成本”估算。免费云额度只减去能够实际抵扣的部分，不能直接从总账单扣除宣传上限。

本版的少量价格数字只是2026-10-03的官网快照，用于展示明确的计价方式，不是购买承诺。Jarvislabs页面预告10月5日调价，Nebius页面同时保留10月1日前后两列；具体条目已经说明采用哪一列。动态市场以匹配条件后的下单报价为准。

短推理或间歇任务可以比较Serverless；连续长训练关注专属实例与稳定性；有可靠断点恢复的批任务可比较Spot。需要CUDA生态时，应确认替代加速器与代码兼容，不能把TPU、AMD GPU和NVIDIA GPU当作完全可替换。
