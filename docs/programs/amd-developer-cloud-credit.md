## 可获得的权益

合格开发者首次可申请 25 小时、约 50 美元的 AMD Instinct MI300X 计算额度，由 AMD 审核决定。

## 申请资格

面向独立开发者和开源贡献者，需说明推理、训练、微调或底层编程用途，并提供有效信用卡。

## 地区与中国大陆适用性

官方页面未列完整地区名单，须满足合作云服务商的账号与地区规则。

## 申请入口与材料

从 AMD Cloud Access 的 Developer Cloud 入口进入合作云平台，注册后填写 Request Credit；获批后通常三个工作日内到账。

## 额度、期限与使用限制

额度到账后十天失效，仅适用 MI300X；不包含附加卷、对象存储和备份。不是每个注册用户自动获赠。

## 费用与到期处理

关机仍扣费或消耗额度，销毁实例才停止实例费用。额度用完或信用卡失效会失去 GPU 与数据访问，需提前导出结果。

## 补充说明

这项短期开发者试用与 AMD AI & HPC Cluster 的学术项目申请不同；ROCm 环境需要检查代码兼容性。
