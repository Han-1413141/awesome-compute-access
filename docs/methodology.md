# 收录方法与覆盖边界

[返回首页](../README.md)

本目录面向需要计算资源的个人、学生、教师、研究人员、开源维护者、非营利组织和创业团队。资料核对基准日为 **2026-10-03（北京时间）**。它是可持续补充的目录，不宣称穷尽全球所有学校、企业和地方政策。

## 收录范围

1. 免费或有明确试用额度的CPU、GPU、TPU、Notebook和云服务。
2. 可用于降低训练、推理或仿真成本的GPU市场、按量实例、Spot及可抢占实例。
3. 学生、教学、科研、超算资源分配计划。
4. 创业云额度、开源维护者支持、非营利组织赠金。
5. 中国大陆平台和有官方公告的地方算力券、补助政策。
6. 模型API额度、与开发工作直接相关的工具支持；明确说明其不等于可出租GPU。

通用软件折扣、纯现金创业融资、域名福利和普通购物优惠不作为主体。投资换股、共享账号、代购教育认证、反复注册领取试用及不明API转售不在收录范围。

## 来源与证据

现有GitHub合集用于发现项目和比较覆盖范围。项目金额、条件与状态优先阅读官方项目页、帮助文档、价目或政府通知，中文文字重新整理，不整段搬运其他仓库。

`official_page` 表示已读官方资料，且条目中的已确认内容有相应官方依据；不意味着公开页面包含所有资格，也不意味着已经注册、通过认证、获得赠金或跑通任务。`official_link_only` 表示只确认入口或部分信息，关键权益尚待核实；`readme_lead` 仅表示第三方线索。后两类不能标记为可使用或需申请。

官方页面可能同时保留过期按钮和当前暂停通知，以明确的状态与日期说明为准。搜索引擎摘要与实时页面不一致时，不将旧摘要中的金额直接当作当前权益。

## 状态含义

| 状态 | 含义 |
|---|---|
| 可使用 `active` | 官方公开提供该方案，仍受地区、账户、付款、库存与限额约束 |
| 需申请或候补 `application_required` | 需要审核、邀请、机构申报或候补，不能保证获批 |
| 暂停申请 `paused` | 官方明确暂不接收新申请 |
| 窗口结束或新用户关闭 `closed` | 指定申报期结束，或不再接收新用户；不必然表示老用户停用 |
| 待核实 `unverified` | 关键条款、入口、当前申请窗口或额度尚未确认 |

政策文件有效期、项目开放状态和本期申报截止日期是不同信息。公告只有历史申报窗口时，不因为政策本身仍在实施就把项目标为当前可申请。候补明确写在项目详情中。

## 金额与价格

“最高”“起”“最多”保留原条件。云抵扣金额、token 数、GPU 小时、核心小时和节点小时不直接相加。学生包等集合入口可能与单项优惠重合，不同计划的金额不能相加宣传为一个人可以领取的总额。

低价栏目提供成本比较入口，不是全市场价格排名。不同卡型、显存、CPU/RAM、区域、付款周期、抢占条件与存储不能混为同一口径。价格快照写明核对日期，公告有未来生效日期时在详情记录。缺失数据写明未公开或待确认，不用博客金额填空。

## 中国大陆适用性

中文页面、可打开的网站和国际项目都不自动意味着中国大陆个人或企业符合资格。详情区分申请主体、机构所在地、企业注册地、服务支持地区与实例部署地区。未找到明确地区条件时直接记录未说明；不指导绕过地区或身份审核。

## 维护原则

金额、截止日期与优惠状态变动由资料贡献者核对后更新。CI只验证数据格式、内部链接和文档一致性。HTTP 200、最近一次Git推送或新增star都不能证明条款有效。

建议优先复查即将截止的申报和价格变更；对长期计划按资源变化再核查。修正受影响条目即可，不为修改一个标点重跑所有外部服务，也不批量刷新没有重新阅读的核对日期。

尚未覆盖所有学校内部HPC、企业定向合作、封闭邀请码及全部城市的每一批次政策；这部分欢迎按官方材料补充。
