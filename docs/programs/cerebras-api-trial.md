## 可获得的权益

## 地区与中国大陆适用性

## 申请入口与材料

注册后完成付款验证，在Limits查看Free Trial配额。

## 额度、期限与使用限制

试用额度用尽或过期后访问停止，需购买额度继续；不同模型限速不同。

## 费用与到期处理

试用不是每天免费；只有主动购买后进入付费使用，具体费用按模型表。
