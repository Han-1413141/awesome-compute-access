**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：Oracle Academy。资源类型：CPU、云抵扣、教学实验。

分类：[学生与教学计划](../categories/education.md)

## 可获得的权益

机构成员教师及学生可使用 Always Free 云资源，并获得有效一年的 300 美元额度；页面列出 Arm 4 核、24GB 内存等免费资源。

## 申请资格

学校须为 Oracle Academy Institutional 会员，教师可为学生配置账号，用于教学及非营利课程、学位相关研究。

## 地区与中国大陆适用性

官方页面未说明完整地区名单；实际云区域与容量依账号供应。

## 申请入口与材料

机构免费加入 Oracle Academy 后，教师通过 Member Hub 申请并管理学生访问。

## 额度、期限与使用限制

300 美元是一年期教育额度，与普通 OCI 新用户试用时长不同。免费资源为 CPU、数据库和存储，未承诺 GPU 配额。

## 费用与到期处理

Always Free 仍受资源限额与供应约束；超额服务及试用到期后处理须看具体账号条款。

## 补充说明

主介绍页未列金额，但独立 Cloud Program 官方页明确列出 300 美元、一年。
