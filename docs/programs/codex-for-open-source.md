## 可获得的权益

入选维护者可获六个月含 Codex 的 ChatGPT Pro；项目还可申请用于开源维护工作的 API 额度及有条件的 Codex Security 访问。

## 申请资格

面向活跃开源项目主要或核心维护者，考虑实际使用、生态重要性和维护贡献；须有有效 ChatGPT 账户及公开 GitHub 信息。

## 地区与中国大陆适用性

受 OpenAI 服务可用地区与适用规则约束；项目页面未列独立地区名单。

## 申请入口与材料

通过官方表单提交 GitHub 项目、维护者角色及用途，滚动审核；API 申请需组织 ID。

## 额度、期限与使用限制

API 额度和 Security 访问需额外评审，不保证三项权益同时获批。API 金额和统一有效期官方页面未说明。

## 费用与到期处理

订阅及额度不可转让、共享或提现；Pro 资助到期后的具体账单处理官方计划页面未说明，须核对获批说明。

## 补充说明

属于开发工具订阅及 API 支持，不是 GPU 训练额度；百万美元基金规模不是单项目授予额。
