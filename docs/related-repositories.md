# 已有仓库调研与本库定位

[返回首页](../README.md)

**核对日期：2026-10-03。结论：已经有人做过，而且有多个直接同类。** 本次检索记录 32 个相关仓库，涵盖免费计算、学生权益、科研资助、创业额度、开源支持和 GPU 价格。本库不声称首创。

## 检索与判断方式

通过 GitHub 与公开搜索交叉检索 `free GPU`、`free compute resources`、`GPU grants`、`research credits`、`student cloud`、`startup credits`、`builder programs`、`算力`、`免费资源` 等关键词，读取仓库说明并用 GitHub API 记录元数据。下面是本轮找到并查看的相关项目，不是全网仓库数量统计。

星标数和最后推送时间是 2026-10-03 的快照。最后推送按 UTC 日期列示，不代表资料逐项复核日期；星标也不证明优惠仍然可领取。程序金额与资格另外查官方来源，不直接继承清单中的数字。

- [Awesome Free AI Compute](https://github.com/chakshurohilla007-design/awesome-free-ai-compute) 已经覆盖免费 GPU、教育、科研、低价和 API，并记录核对与历史信息。
- [Awesome Builder Programs](https://github.com/doanbactam/awesome-builder-programs) 横跨学生、开源、创业与 AI 支持，和本题的人群范围高度重合。
- [AI Resource Radar](https://github.com/ai-resource-radar/ai-resource-radar) 与 [free-resources](https://github.com/caozuohua/free-resources) 已提供中文说明及结构化资料。中文、核对日期或 JSON 本身不是新方向。
- [Awesome Grants](https://github.com/yueyueL/awesome-grants) 与 [GPU Grants](https://github.com/eric-prog/GPU-Grants) 是科研和训练资源的重要线索。
- [Sourcey Startup Credits](https://github.com/sourcey/startup-credits) 与 [Awesome AI Dev Funding](https://github.com/pleasedodisturb/awesome-ai-dev-funding) 已把资格、来源和机器可读数据做成维护流程。

本库的工作重点是把计算资源相关计划展开为中文申请说明，逐项区分资源类型、申请身份、地区、额度与期限、到期费用和当前状态，并补充国内平台与地方政策。它与上述项目有重合，也可以相互补充。
