# Google for Startups Cloud Program

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：Google Cloud。资源类型：云抵扣、CPU、GPU、TPU、API。

分类：[创业扶持与云额度](../categories/startup.md)

## 可获得的权益

未融资团队可申请2000美元；Seed至Series A普通档最高200,000美元，AI-first档最高350,000美元。

## 申请资格

按公司融资阶段和AI业务属性申请，不是个人开发者自动赠金。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

选择Pre-funded或Early stage入口，提交企业、融资和云使用计划。

## 额度、期限与使用限制

最高金额为对应档位上限；分年抵扣比例、既往领取和GPU/TPU配额要看该档规则。

## 费用与到期处理

超出赠金、产品排除项及后续抵扣比例会形成自付费用。

核实层级：已读官方资料。核对日期表示阅读或检查来源的日期，不代表实际注册、获批、付费或运行验证。
