提供方：Anthropic。资源类型：API。

分类：[科研资助与超算分配](../categories/research.md) · [模型 API 与推理额度](../categories/api.md)

## 可获得的权益

为重点研究提供 Claude API 额度，通常最高 1,000 美元，特殊需求可说明；优先支持 AI 安全、对齐及相关研究。

## 申请资格

研究者须提交研究计划，可由团队使用同一 Claude Console 组织申请。

## 地区与中国大陆适用性

仅限 Anthropic 官方支持的国家和地区，不能把该计划视为绕过服务地区限制的途径。

## 申请入口与材料

通过官方帮助页所链表单申请，通常在每月第一个星期一审阅申请。

## 额度、期限与使用限制

只适用于 API，不适用于 Claude 网页订阅；不提供未公开模型访问，也不包含模型微调。统一有效期官方页面未说明。

## 费用与到期处理

超出授予额度的 API 调用按账号计费；本计划不提供可自行部署模型的 GPU。

## 补充说明

API 调用额度与 Claude for Science、开源维护者订阅支持是独立计划。
