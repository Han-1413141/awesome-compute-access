提供方：GitHub。资源类型：云抵扣。

分类：[开源项目支持](../categories/open-source.md)

## 可获得的权益

入选项目可获 10,000 美元 Azure 额度及 10,000 美元分阶段现金资助，并参加开源安全培训。

## 申请资格

维护者须满 18 岁，项目在 GitHub 活跃、具有明确开源许可及一定使用基础；须满足 GitHub Sponsors 支持地区要求。

## 地区与中国大陆适用性

GitHub Sponsors 支持的地区，另按项目资格审核。

## 申请入口与材料

滚动提交申请并参加面试；每个团队最多两人参加。

## 额度、期限与使用限制

包含约三周、15 小时的培训，以及 6 和 12 个月后的跟进。Azure 额度有效期官方页面未说明，也不保证 GPU 配额。

## 费用与到期处理

现金与云抵扣不同，Azure 额度不能自由提现；超出覆盖的 Azure 使用可能收费。

## 补充说明

页面另提到最高 15 万美元创业计划，需要另行满足资格，不能并入本基金的保证权益。
