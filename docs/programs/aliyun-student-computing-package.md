# 阿里云学生专属算力包

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：可使用**　｜　**资料核对：2026-10-03**

提供方：阿里云。资源类型：CPU、云抵扣。

分类：[学生与教学计划](../categories/education.md) · [低价 GPU 与按量计算](../categories/low-cost.md)

## 可获得的权益

提供练手、毕设、科创三档 CPU 算力包；练手包优惠价 19 元，含 150 元计算抵扣额度、有效期一个月。

## 申请资格

已认证中国内地高校学生；企业认证账号、同人账号、欠费账号等不能购买。

## 地区与中国大陆适用性

指定地域含北京、杭州、乌兰察布、河源、弗吉尼亚，以购买页可选项为准。

## 申请入口与材料

进入学生算力包购买入口选择套餐；毕设、科创档可按文档规则叠加学生券。

## 额度、期限与使用限制

每次仅一个有效包；各档有小时抵扣上限和指定 CPU 规格，不是 GPU 免费包。

## 费用与到期处理

到期实例不会自动释放，会转按量收费；超出抵扣、额外流量和扩盘另计费用。

## 补充说明

长期档包括毕设包 850 元额度／6 个月、科创包 2000 元额度／6 个月；额度不等于购买价格。
