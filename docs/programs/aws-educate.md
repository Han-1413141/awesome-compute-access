提供方：AWS。资源类型：教学实验、CPU。

分类：[学生与教学计划](../categories/education.md) · [免费计算与云试用](../categories/free-compute.md)

## 可获得的权益

免费提供自学课程与实际操作实验，覆盖 S3、EC2、VPC、数据库等入门云服务。

## 申请资格

年满 13 岁的学习者即可注册，不要求必须在校，也不需要信用卡。

## 地区与中国大陆适用性

官网面向全球学习者；具体实验可用性与账号规则以平台为准。

## 申请入口与材料

使用电子邮箱在 AWS Educate 官网注册后选择课程和实验。

## 额度、期限与使用限制

这是受课程约束的实验环境，不能把历史 AWS Educate 云代金券金额当作现行权益。实验时长和资源依课程，不支持任意持续 GPU 训练。

## 费用与到期处理

项目内学习和实验免费；自行开通独立 AWS 商业账户不属于同一免费保障。

## 补充说明

应归入教学实验，不应与自由使用的云服务器额度或 AWS 新用户免费层合并。
