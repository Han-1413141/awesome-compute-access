# Azure for Students

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：Microsoft Azure。资源类型：云抵扣、CPU、API。

分类：[学生与教学计划](../categories/education.md)

## 可获得的权益

符合条件的全日制大学生可获得 100 美元 Azure 额度，有效 12 个月；保持学生资格可每年续领。

## 申请资格

需要学校身份验证及合格学校邮箱，每人限一个账号，用于教学、非商业研究、开发与演示。

## 地区与中国大陆适用性

以注册地区及学生资格验证结果为准；官网页面未给出保证中国大陆学生均可使用的承诺。

## 申请入口与材料

从 Azure for Students 官方页面注册并验证学生身份，不要求信用卡。

## 额度、期限与使用限制

额度不能用于 Azure Marketplace 等排除项目。提供云额度不等于获得 GPU 配额，不能保证直接 GPU 训练。

## 费用与到期处理

用完 100 美元后，不升级则订阅停用；主动升级到按量付费才进入对应收费规则。

## 补充说明

年度续领取决于重新确认学生资格，不能写成永久每年自动发放。

核实层级：已读官方资料。核对日期表示阅读或检查来源的日期，不代表实际注册、获批、付费或运行验证。
