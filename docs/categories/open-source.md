# 开源项目支持

[返回首页](../../README.md) · [全部项目](../catalog.md)

共 10 项；其中可使用或需申请 9 项，暂停、历史或待核实 1 项。

申请制项目仍需审核；候补状态、地区限制和实际资源类型请打开详情查看。

| 项目 | 资源 | 权益摘要 | 状态 | 核对日期 |
|---|---|---|---|---|
| [AMD Developer Cloud 开发者试用](../programs/amd-developer-cloud-credit.md) | GPU / 云抵扣 | 合格开发者首次可申请 25 小时、约 50 美元的 AMD Instinct MI300X 计算额度，由 AMD 审核决定。 | 需申请或候补 | 2026-10-03 |
| [Claude for Open Source](../programs/claude-for-open-source.md) | 工具订阅 | 入选者获得六个月 Claude Max 20x，初始规模最多 10,000 名，可由 Anthropic 扩大。 | 需申请或候补 | 2026-10-03 |
| [fal Research Grants](../programs/fal-research-grants.md) | GPU / 云抵扣 | 为有价值的开源 AI 项目提供免费计算支持，官方展示了使用资助训练开源模型的案例。 | 需申请或候补 | 2026-10-03 |
| [GitHub Secure Open Source Fund](../programs/github-secure-open-source-fund.md) | 云抵扣 | 入选项目可获 10,000 美元 Azure 额度及 10,000 美元分阶段现金资助，并参加开源安全培训。 | 需申请或候补 | 2026-10-03 |
| [Hugging Face Community GPU Grants](../programs/hugging-face-community-gpu-grants.md) | GPU | 创新性的社区 Spaces 可申请免费 GPU 硬件升级，由 Hugging Face 承担获批升级的费用。 | 需申请或候补 | 2026-10-03 |
| [Hugging Face Spaces CPU Basic（需付费计划）](../programs/huggingface-spaces-cpu.md) | CPU | CPU Basic本身不收按小时硬件费，默认2 vCPU、16GB内存与50GB非持久磁盘；普通计算Space有计划门槛。 | 可使用 | 2026-10-03 |
| [Codex for Open Source](../programs/codex-for-open-source.md) | 工具订阅 / API | 入选维护者可获六个月含 Codex 的 ChatGPT Pro；项目还可申请用于开源维护工作的 API 额度及有条件的 Codex Security 访问。 | 需申请或候补 | 2026-10-03 |
| [华为开发者空间免费云开发环境](../programs/huawei-developer-space.md) | CPU / 教学实验 | 官网展示 180 小时免费资源算力，提供云桌面、云服务器、容器及多种开发工具，覆盖鲲鹏、昇腾、鸿蒙等开发实践。 | 可使用 | 2026-10-03 |
| [启智 OpenI AI 协作平台](../programs/openi-forge.md) | GPU / NPU / 教学实验 | 官方项目介绍提供免费云端 GPU/NPU 算力，并整合代码、数据集、镜像及模型调试、训练、推理功能。 | 可使用 | 2026-10-03 |
