## 可获得的权益

合格学术研究者可获得 Gemini API 额度及更高速率限制，支持评测、科学发现、具身智能和多模态等实验。

## 申请资格

必须关联有效学术机构或学术研究组织，官方举例包括教师、研究人员及博士生；按研究项目申请。

## 地区与中国大陆适用性

仅限 Gemini API 支持的国家和地区。

## 申请入口与材料

从 Gemini for Research 官方文档进入申请表，按月审核。

## 额度、期限与使用限制

每项目金额、有效期和提高后的具体速率官方页面未说明，访问权和额度由 Google 决定授予或撤回。

## 费用与到期处理

提供模型调用资源，不提供可自行训练任意模型的 GPU；额度外调用须按适用账户规则管理。

## 补充说明

研究资助和 Gemini API 的普通免费层是不同项目，不能把二者的资格及限制混写。
