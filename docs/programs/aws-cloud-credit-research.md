# AWS Cloud Credit for Research

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：AWS。资源类型：云抵扣、CPU、GPU。

分类：[科研资助与超算分配](../categories/research.md)

## 可获得的权益

研究生最高可申请 5,000 美元 AWS 额度；教师与研究人员没有固定申请上限，按提案与预算评审。

## 申请资格

认证研究机构的全职教师、研究人员或研究生，必须使用机构邮箱。支持有限期限的云迁移、基准测试、可复用研究工具及高级工作坊。

## 地区与中国大陆适用性

官方 FAQ 明确目前无法处理大中华区申请；其他地区研究者可申请，印度由当地 AWS 实体管理。

## 申请入口与材料

准备 AWS 账户、机构身份、研究提案和费用预算，全年受理，官网给出的审理时间为 90–120 天。

## 额度、期限与使用限制

不资助实验室日常运营、行政工作和持续的一般研究。EC2 限按需或 Spot；GPU 配额须另行满足。完整有效期官方页面未说明。

## 费用与到期处理

额度不覆盖所有服务，耗尽或过期后的资源可能收费。

## 补充说明

“全球开放”必须保留大中华区例外。官网计费 FAQ 子链接已重定向，未凭第三方补写有效期。
