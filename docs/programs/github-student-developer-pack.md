# GitHub Student Developer Pack

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：GitHub。资源类型：CPU、云抵扣、工具订阅。

分类：[学生与教学计划](../categories/education.md)

## 可获得的权益

通过学生认证后可领取开发工具和合作方权益；当前学生包列有 Codespaces Pro 等级访问、Azure 学生入口等。各合作权益按自己的条件领取。

## 申请资格

年满 13 岁、在授予学位或文凭的课程中就读，持 GitHub 个人账号并证明在读身份。教师或研究人员不能仅凭任职身份领取学生包。

## 地区与中国大陆适用性

GitHub 学生认证与每个合作服务的地区限制分别适用；通过学生认证不代表所有云服务在所在地可用。

## 申请入口与材料

在 GitHub 账号 Education benefits 中开始申请，按提示提交学校邮箱或带当前日期的学生证、课表、成绩单、在读证明等。

## 额度、期限与使用限制

学生认证有效两年，之后需重新认证。第三方限时权益不能通过重新认证重复领取，也可能不能与已领取试用叠加。

## 费用与到期处理

学生包本身不是统一现金余额；各云服务的绑卡、超额与到期计费分别核对。Codespaces 也有用量边界，未承诺 GPU。

## 补充说明

本条是教育认证及权益集合入口。Azure、Heroku、Codespaces 的独立条目用于解释具体服务，不能与本条重复累加权益金额。

核实层级：已读官方资料。核对日期表示阅读或检查来源的日期，不代表实际注册、获批、付费或运行验证。
