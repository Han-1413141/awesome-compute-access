## 可获得的权益

获批后提供总计 312 美元平台额度，按每月 13 美元使用 24 个月，可用于 Dynos、Postgres 和 Key-Value Store 等 Heroku 产品。

## 申请资格

须满 18 岁、已加入 GitHub Student Developer Pack，并提供有效信用卡或借记卡；每人只能参加当前计划一次。

## 地区与中国大陆适用性

官方优惠页未列完整地区名单，仍须通过 GitHub 与 Heroku 各自账号和付款验证。

## 申请入口与材料

先完成 GitHub 学生认证，进入 Heroku 学生优惠页，登录 Heroku 账号并提交申请。

## 额度、期限与使用限制

每月未用额度不结转；从获批当月一日开始计算当月额度，月末清零。不适用于付费第三方 Add-ons 或 Heroku Teams。

## 费用与到期处理

超过每月 13 美元会向绑定卡扣款；24 个月结束后，继续保留收费资源会产生账单。

## 补充说明

这是应用托管与数据服务额度，未提供可自行训练模型的 GPU。学生包资格和此计划额外年龄条件不同。
