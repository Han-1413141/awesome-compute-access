# OVHcloud Startup Program

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：OVHcloud。资源类型：云抵扣、CPU、GPU。

分类：[创业扶持与云额度](../categories/startup.md)

## 可获得的权益

Start档12个月10,000欧元云额度及6小时工程支持；Scale档12个月最高100,000欧元与最高20小时支持。

## 申请资格

创业或成长型企业，按Start/Scale标准审核。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

选择匹配发展阶段的入口，提交公司、产品和云需求资料。

## 额度、期限与使用限制

Start和Scale是不同等级，不能相加承诺；GPU覆盖与可用资源需按权益及库存确认。

## 费用与到期处理

项目到期、额度超出或未覆盖产品产生自付费用。
