## 可获得的权益

获批研究者最高可获得 1,000 美元 API 额度，发放后有效 12 个月。

## 申请资格

研究应服务于负责任部署、安全或社会影响等方向，鼓励处于早期阶段、资金和机构资源有限的研究者申请。

## 地区与中国大陆适用性

仅在 OpenAI API 支持的国家和地区提供，申请不会解除地区限制。

## 申请入口与材料

从官网表单提交研究提案；3、6、9、12 月按季度审核，决定后通常需 4–6 周发放额度。

## 额度、期限与使用限制

额度不能延期或续期，用于公开可用的 API 模型；不是 ChatGPT 订阅，也不提供 GPU 实例。

## 费用与到期处理

超过或不属于资助范围的 API 使用可能产生费用，应核对对应组织和项目的预算设置。

## 补充说明

该额度支持 API 实验，不能写成可自由训练任意大模型的 GPU 资助。
