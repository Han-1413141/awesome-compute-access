# AWS Academy Learner Lab

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：AWS Academy。资源类型：教学实验、CPU。

分类：[学生与教学计划](../categories/education.md)

## 可获得的权益

为高等教育课程提供可持续使用的云实验环境，教师可布置任务并查看学生花费，平台覆盖 100 多项 AWS 服务。

## 申请资格

由合格高等教育机构加入 AWS Academy，授权教师完成入门要求后邀请课程学生。

## 地区与中国大陆适用性

面向参加 AWS Academy 的机构；具体国家与成员资格以机构申请审核为准。

## 申请入口与材料

教师或机构管理人员使用机构邮箱申请加入，再通过课程为学生开通实验。

## 额度、期限与使用限制

不是学生个人直接领取的独立商业账户。每名学生当前统一额度、期限和可用 GPU 官方主页面未说明，取决于实验配置。

## 费用与到期处理

教师须管理实验预算与允许的服务；不能把第三方常见的“每人 100 美元”当作所有课程保证。

## 补充说明

与无需学校加入的 AWS Educate 不同，机构和教师是 Learner Lab 的开通入口。
