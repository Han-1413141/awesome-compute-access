# Azure Grant for Nonprofits

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：Microsoft。资源类型：云抵扣、CPU。

分类：[公益与非营利支持](../categories/nonprofit.md)

## 可获得的权益

通过资格验证的非营利组织每年可申请 2,000 美元 Azure 额度，用于 Microsoft 发布的合格 Azure 服务。

## 申请资格

须具有当地认可的非营利法律地位及公益使命；个人、学校、大学等列为不符合此计划的主体。

## 地区与中国大陆适用性

非营利优惠覆盖多个国家和地区，但具体 Azure 产品和可用云区域会有差异。

## 申请入口与材料

由组织员工或符合条件的志愿管理人员完成 Microsoft 非营利验证，再激活 Azure 资助。

## 额度、期限与使用限制

额度使用期 12 个月，未用余额不结转；保持资格可每年续领。并非现金，也不保证 GPU 配额。

## 费用与到期处理

需要信用卡；用完 2,000 美元后订阅转为按量付费，继续运行的资源会收费。

## 补充说明

当前官方额度为每年 2,000 美元，不能沿用旧清单中的 3,500 美元。

## 官方依据与核实范围

核实层级：已读官方资料。核对日期表示阅读或检查来源的日期，不代表实际注册、获批、付费或运行验证。
