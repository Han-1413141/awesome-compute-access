## 可获得的权益

获批后为指定 Google Cloud 项目临时授予免费 Cloud TPU 配额，可运行适配 TPU 的模型训练。

## 申请资格

任何人可以登记研究兴趣，由项目滚动审核邀请。参与者须公开研究成果、向 Google 提供使用反馈，并遵守项目条款。

## 地区与中国大陆适用性

官方页面未说明完整地区名单；最终仍受 Google Cloud 服务可用性与项目审核约束。

## 申请入口与材料

在 TRC 官网提交 Express interest 表单，获邀后接受邀请并配置项目。

## 额度、期限与使用限制

每人设备数、统一到期日官方页面未说明。TRC 配额不兼容 CMLE、CAIP、Vertex 工作流；TPU 代码需要框架适配，不能当作 CUDA GPU。

## 费用与到期处理

免费范围是 TPU；驱动 TPU 的普通虚拟机与 Cloud Storage 等其他 GCP 服务收费。

## 补充说明

官网所述 1,000 多台设备是项目资源池规模，不能写成每个申请人的额度。
