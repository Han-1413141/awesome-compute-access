# AWS Nonprofit Credit Program

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：AWS / TechSoup。资源类型：云抵扣、CPU。

分类：[公益与非营利支持](../categories/nonprofit.md) · [低价 GPU 与按量计算](../categories/low-cost.md)

## 可获得的权益

通过 TechSoup 发放最高 5,000 美元 AWS 额度；美国普通非营利档位为 1,000、2,000 或 5,000 美元，按组织预算选择。

## 申请资格

须为认可的非营利组织或合格公共图书馆；学校和大学不在此计划范围。海外通过 TechSoup 当地伙伴验证。

## 地区与中国大陆适用性

官方称全球计划，具体资格与档位由所在地 TechSoup 伙伴确认。

## 申请入口与材料

先完成组织验证再请求额度，每个财政年度可申请一次，有效期至少一年或至用完。

## 额度、期限与使用限制

适用于符合条件的按量服务；不覆盖预留实例预付费、Marketplace、域名等排除项目，不保证 GPU 配额。

## 费用与到期处理

美国标准档管理费分别为 95、190、475 美元，故不是零成本；额度耗尽或过期后账户继续收费。

## 补充说明

特定美国互助金融类非营利组织另有 5,000 美元额度、500 美元管理费方案；不得把不同资格档位当作官方金额冲突。
