## 可获得的权益

可使用按模型限速的推理API；官方Rate Limits分别列请求和token限制。

## 申请资格

支持地区的GroqCloud账户；实际额度按组织Limits页面。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

创建API key并选支持模型，读取响应限速信息和控制台组织限额。

## 额度、期限与使用限制

按组织而非每个用户计量；RPM、TPM、每日请求或音频时长任一先触发就限流。

## 费用与到期处理

付费升级和超出免费方案按选定服务计费；免费API不是可训练自有模型的GPU。
