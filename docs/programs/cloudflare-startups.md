# Cloudflare for Startups

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：Cloudflare。资源类型：CPU、API、云抵扣。

分类：[创业扶持与云额度](../categories/startup.md)

## 可获得的权益

一年内最高10,000/100,000/350,000美元三级额度；自筹资金档无最低融资要求。

## 申请资格

按融资额及是否由合作机构支持分档，并需满足成立年限等要求。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

准备公司网站、企业邮箱和融资资料，通过项目表单申请并关联Cloudflare账户。

## 额度、期限与使用限制

Workers AI抵扣有最高50,000美元子上限，R2最高10,000美元；不含Registrar及AI Gateway。

## 费用与到期处理

要求有效付款方式；子额度、总额度或期限超出后可自动计费。

## 补充说明

边缘平台/API权益，不是可以SSH使用的GPU服务器。
