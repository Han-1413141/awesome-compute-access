# Azure 免费账户

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：可使用**　｜　**资料核对：2026-10-03**

提供方：Microsoft Azure。资源类型：CPU、云抵扣。

分类：[免费计算与云试用](../categories/free-compute.md)

## 可获得的权益

新用户可获200美元、30天试用；部分产品12个月免费，部分产品有长期按月免费量。

## 申请资格

符合新客户条件，需按注册流程提供身份与付款验证。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

创建免费账户并核对每个产品的免费SKU及额度；学生另看Azure for Students。

## 额度、期限与使用限制

免费虚拟机列表主要是指定CPU规格；Azure Machine Learning管理服务免费不等于训练VM免费。

## 费用与到期处理

30天或赠金耗尽后继续使用需要转按量付费；注册可能有1美元临时授权。
