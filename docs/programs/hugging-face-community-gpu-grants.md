## 可获得的权益

创新性的社区 Spaces 可申请免费 GPU 硬件升级，由 Hugging Face 承担获批升级的费用。

## 申请资格

以具体 Space 项目的创新价值和社区用途申请；官网未列统一学历或机构要求。

## 申请入口与材料

进入 Space 的硬件设置，在休眠设置下方使用 Community GPU grant 申请入口。

## 额度、期限与使用限制

具体 GPU 型号、时长和额度官方页面未说明。资助针对 Spaces 应用演示，不是通用 GPU 虚拟机或长期训练集群保证。

## 费用与到期处理

未获资助的付费硬件按运行时间收费，即使应用无人使用也可能计费；须确认哪些硬件由资助覆盖。

## 补充说明

不要与 ZeroGPU 共享配额或 CPU Basic 混为同一权益；本条只记录需审批的社区硬件资助。
