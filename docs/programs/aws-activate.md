# AWS Activate 创业支持

[返回首页](../../README.md) · [全部项目](../catalog.md)

**状态：需申请或候补**　｜　**资料核对：2026-10-03**

提供方：AWS。资源类型：云抵扣、CPU、API、GPU。

分类：[创业扶持与云额度](../categories/startup.md)

## 可获得的权益

Founders先1000美元，部分参与者最高5000美元；Portfolio最高200,000美元；更高AI档为邀请制。

## 申请资格

成立10年内、Pre-Series B、Paid Tier账户；Portfolio需Activate合作方Org ID。

## 地区与中国大陆适用性

国际服务；本页未列完整可申请地区，需按注册主体与服务支持地区核对。

## 申请入口与材料

用企业邮箱创建Builder ID，选档位，填写产品与融资资料并关联AWS账户。

## 额度、期限与使用限制

不同档位和历史已领金额会影响审批；GPU仍受区域库存、配额及抵扣范围限制。

## 费用与到期处理

Paid账户超出赠金或使用不覆盖产品会收费；额度到期日以获批通知为准。
