## 可获得的权益

入选者获得六个月 Claude Max 20x，初始规模最多 10,000 名，可由 Anthropic 扩大。

## 申请资格

个人须成年、GitHub 账户至少两年、90 天内有公开贡献并参与 OSI 许可项目。维护者可按依赖数、下载量、贡献或关键性门槛申请，也有生态影响通道。

## 地区与中国大陆适用性

须为提供 Claude.ai 服务地区的法律居民，并符合适用限制。

## 申请入口与材料

通过官方申请入口用 GitHub 验证，提交用途与资格说明，滚动审核；获批礼码须在 90 天内激活。

## 额度、期限与使用限制

每人同时仅一份，满足门槛不保证获批。六个月从激活日起计，不包含通用 API 余额或 GPU；续申仍须审核。

## 费用与到期处理

额外用量可能收费；此前付费订阅会在资助结束后恢复原计划及价格，原免费账号则回到免费计划。

## 补充说明

当前维护者标准含 500 个依赖仓库、100 个依赖包或月下载 20 万等路径，不沿用旧第三方清单的星标门槛。
